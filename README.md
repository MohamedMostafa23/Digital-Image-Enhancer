# Digital-Image-Enhancer

A desktop image-processing exercise for comparing spatial and frequency-domain operations. The [Python implementation](Image%20Proccessing%20and%20Histogram%20Task.py) includes an interactive interface for filtering and histogram-based enhancement. The screenshots show the interface and example results.
